# Security Policy

Do not report security vulnerabilities in a public Issue.

For a suspected vulnerability in Luma, email [qq927884591@gmail.com](mailto:qq927884591@gmail.com) with a concise description, affected Luma and macOS versions, and safe reproduction details. Do not include passwords, access tokens, personal information, or complete sensitive logs.

This repository is a public product-information and feedback hub. Security reports are handled privately through the email address above.

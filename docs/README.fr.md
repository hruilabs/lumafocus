# Luma

> Faites de la pause un geste naturel, avant que la fatigue visuelle ne s'installe.

[English](../README.md) | [简体中文](README.zh-Hans.md) | [繁體中文](README.zh-Hant.md) | [日本語](README.ja.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md)

Luma est un compagnon de rythme de travail discret pour macOS. Il reste silencieux pendant que vous vous concentrez et vous invite doucement à faire une pause quand un temps de récupération est nécessaire.

[Visiter le site](https://www.lumafocus.cn/fr/) · [Obtenir sur le Mac App Store](https://apps.apple.com/fr/app/luma-minuteur-de-pause/id6758292332?mt=12&uo=4) · [Signaler un problème](https://github.com/hruilabs/lumafocus/issues/new?template=bug_report.yml) · [Suggérer une fonctionnalité](https://github.com/hruilabs/lumafocus/issues/new?template=feature_request.yml) · [Voir les problèmes connus](https://github.com/hruilabs/lumafocus/issues)

## Ce dépôt

Ce dépôt est le centre public d'information produit et de retours pour Luma. Il présente le produit et recueille les problèmes d'utilisation ainsi que les suggestions de fonctionnalités.

Luma est un logiciel propriétaire. Ce dépôt ne contient ni le code source de l'application, ni son implémentation interne, ni de versions distribuables. Merci de ne pas y soumettre de code d'application ni de pull request.

## Ce que vous pouvez faire ici

- Signaler un problème de fonctionnalité ou d'expérience
- Suggérer une fonctionnalité ou décrire un cas d'usage
- Consulter les problèmes connus et leur avancement

Pour un issue, indiquez si possible la version de Luma, la version de macOS, les étapes de reproduction et le résultat attendu comme le résultat obtenu. N'ajoutez jamais de mots de passe, jetons, données personnelles ou autres informations sensibles dans un issue public.

## La direction de Luma

- Interrompre le moins possible le travail en cours
- Offrir des rappels calmes et compréhensibles lorsque la fatigue s'accumule
- Faire de la pause un rythme naturel plutôt qu'une tâche supplémentaire

# Luma

> 在用眼过度前，让休息自然发生。

[English](../README.md) | [简体中文](README.zh-Hans.md) | [繁體中文](README.zh-Hant.md) | [日本語](README.ja.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md)

Luma 是一款面向 macOS 的低打扰工作节律伴侣。它在你专注时安静工作，在需要恢复时以轻柔的方式提醒你停下来。

[访问官网](https://www.lumafocus.cn/) · [在 Mac App Store 获取](https://apps.apple.com/cn/app/%E5%BE%AE%E5%85%89%E4%BC%91%E6%81%AF%E6%8F%90%E9%86%92/id6758292332?mt=12&uo=4) · [报告问题](https://github.com/hruilabs/lumafocus/issues/new?template=bug_report.yml) · [提出功能建议](https://github.com/hruilabs/lumafocus/issues/new?template=feature_request.yml) · [查看已知问题](https://github.com/hruilabs/lumafocus/issues)

## 这个仓库是什么

这里是 Luma 的公开产品信息与反馈中心，用于发布产品信息、收集体验问题和功能建议。

Luma 是闭源软件。本仓库不包含应用源码、内部实现或可分发构建；请不要向这里提交应用代码或 Pull Request。

## 你可以在这里做什么

- 报告功能异常或体验问题
- 提出功能建议和使用场景
- 查看已知问题与处理进展

提交问题时，请尽量提供 Luma 版本、macOS 版本、复现步骤以及预期与实际结果。不要在公开 Issue 中包含密码、令牌、个人隐私或其他敏感信息。

## Luma 的方向

- 尽量不打断正在进行的工作
- 在疲劳累积时给出温和、可理解的提醒
- 让休息成为自然发生的节奏，而不是额外负担

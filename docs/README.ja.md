# Luma

> 目の負担が高まる前に、休憩を自然に。

[English](../README.md) | [简体中文](README.zh-Hans.md) | [繁體中文](README.zh-Hant.md) | [日本語](README.ja.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md)

Luma は、macOS 向けの、作業をなるべく妨げないリズム管理アプリです。集中している間は静かに動作し、回復が必要なときだけ穏やかに休憩を促します。

## このリポジトリについて

ここは Luma の公開プロダクト情報・フィードバック窓口です。プロダクト情報を共有し、利用時の問題や機能提案を受け付けます。

Luma はクローズドソースです。このリポジトリにはアプリケーションのソースコード、内部実装、配布用ビルドは含まれていません。アプリケーションコードや Pull Request は送らないでください。

## ここでできること

- 機能または利用体験の問題を報告する
- 機能や利用シーンを提案する
- 既知の問題と対応状況を確認する

Issue には、可能な範囲で Luma のバージョン、macOS のバージョン、再現手順、期待した結果と実際の結果を記載してください。公開 Issue にパスワード、トークン、個人情報、その他の機密情報を含めないでください。

## Luma の方向性

- 進行中の作業をできるだけ中断しない
- 疲労がたまったときに、落ち着いた理解しやすいリマインダーを届ける
- 休憩を追加の作業ではなく、自然なリズムにする

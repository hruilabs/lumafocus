# Luma

> Haz que el descanso ocurra de forma natural, antes de que aumente la fatiga visual.

Luma es un acompañante de ritmo de trabajo de baja interrupción para macOS. Permanece en silencio mientras te concentras y te ofrece avisos suaves cuando es momento de recuperarte.

## Qué es este repositorio

Este es el centro público de información y comentarios de Luma. Comparte información del producto y recibe informes de experiencia y solicitudes de funciones.

Luma es software de código cerrado. Este repositorio no contiene el código fuente de la aplicación, la implementación interna ni compilaciones distribuibles. No envíes código de la aplicación ni pull requests aquí.

## Qué puedes hacer aquí

- Informar de un problema funcional o de experiencia
- Sugerir una función o describir un caso de uso
- Revisar los problemas conocidos y su progreso

Al crear un issue, incluye cuando corresponda la versión de Luma, la versión de macOS, los pasos para reproducir el problema y el comportamiento esperado y real. No incluyas contraseñas, tokens, datos personales ni otro material sensible en issues públicos.

## El rumbo de Luma

- Interrumpir lo menos posible el trabajo en curso
- Ofrecer recordatorios tranquilos y comprensibles cuando aumenta la fatiga
- Hacer del descanso un ritmo natural, no una tarea más

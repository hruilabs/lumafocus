Luma 是一款為 macOS 設計、低打擾的工作節律夥伴。你專注時它會安靜運作；需要恢復時，才以輕柔方式提醒你暫停一下。

## 這個儲存庫是什麼

這裡是 Luma 的公開產品資訊與意見回饋中心，用來分享產品資訊、收集使用問題與功能建議。

Luma 是閉源軟體。本儲存庫不包含應用程式原始碼、內部實作或可散發的建置版本；請不要在此提交應用程式碼或 Pull Request。

## 你可以在這裡做什麼

- 回報功能或使用體驗問題
- 提出功能建議與使用情境
- 查看已知問題與處理進度

提交 Issue 時，請盡量提供 Luma 版本、macOS 版本、重現步驟與預期、實際結果。請勿在公開 Issue 中包含密碼、權杖、個人資訊或其他敏感資料。

## Luma 的方向

- 盡量不打斷正在進行的工作
- 在疲勞累積時提供溫和、容易理解的提醒
- 讓休息成為自然的節奏，而不是額外負擔

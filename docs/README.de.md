# Luma

> Mach Pausen ganz natürlich, bevor die Augen überlastet sind.

[English](../README.md) | [简体中文](README.zh-Hans.md) | [繁體中文](README.zh-Hant.md) | [日本語](README.ja.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Español](README.es.md)

Luma ist ein unaufdringlicher Begleiter für den Arbeitsrhythmus auf macOS. Während du konzentriert arbeitest, bleibt es im Hintergrund und gibt dir sanfte Hinweise, wenn Zeit zur Erholung ist.

[Website besuchen](https://www.lumafocus.cn/de/) · [Im Mac App Store laden](https://apps.apple.com/de/app/luma-sanfter-pausen-timer/id6758292332?mt=12&uo=4) · [Fehler melden](https://github.com/hruilabs/lumafocus/issues/new?template=bug_report.yml) · [Funktion vorschlagen](https://github.com/hruilabs/lumafocus/issues/new?template=feature_request.yml) · [Bekannte Probleme](https://github.com/hruilabs/lumafocus/issues)

## Dieses Repository

Dies ist Lumas öffentliches Informations- und Feedback-Repository. Hier finden sich Produktinformationen sowie Möglichkeiten, Erfahrungen und Funktionswünsche mitzuteilen.

Luma ist Closed-Source-Software. Dieses Repository enthält keinen Anwendungscode, keine interne Implementierung und keine verteilbaren Builds. Bitte reiche hier keinen Anwendungscode und keine Pull Requests ein.

## Das kannst du hier tun

- Ein Funktions- oder Nutzungsproblem melden
- Eine Funktion oder einen Anwendungsfall vorschlagen
- Bekannte Probleme und ihren Fortschritt ansehen

Gib bei einem Issue möglichst die Luma-Version, die macOS-Version, Schritte zum Reproduzieren sowie erwartetes und tatsächliches Verhalten an. Veröffentliche keine Passwörter, Tokens, persönlichen Daten oder andere vertrauliche Informationen in öffentlichen Issues.

## Lumas Richtung

- Laufende Arbeit so wenig wie möglich unterbrechen
- Ruhige und verständliche Erinnerungen geben, wenn Ermüdung zunimmt
- Pausen zu einem natürlichen Rhythmus machen, nicht zu einer weiteren Aufgabe
